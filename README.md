# 雅思听力场景词汇点读

把《听力场景词汇表》整理成适合雅思听力备考的可搜索、可分类、可收藏网页点读工具。

## 在线使用

### [点击打开雅思听力场景词汇点读 →](https://gracegejiaqi.github.io/listening-vocab-reader/)

## 功能

- 914 个英语场景词汇，覆盖 12 类雅思听力高频场景
- 点击词卡即可使用浏览器英语语音朗读
- 英文与中文释义搜索
- 慢、中、快三档语速
- 隐藏释义、自测、收藏与随机练习
- 手机、平板和电脑自适应布局

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

构建检查：

```bash
npm test
```

词汇数据位于 `app/vocab-data.json`，页面代码位于 `app/page.tsx`。
